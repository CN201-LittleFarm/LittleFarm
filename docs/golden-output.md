# Little Farm - Golden Output

## 1. วัตถุประสงค์ (Purpose)

เอกสารนี้จัดทำขึ้นเพื่อบันทึกพฤติกรรมของเกม Little Farm เวอร์ชันดั้งเดิมก่อนการ Refactoring โดยใช้ผลลัพธ์ที่ได้จากการทดลองเล่นจริงเป็นข้อมูลอ้างอิง (Baseline)

ผลลัพธ์เหล่านี้จะถูกนำไปใช้ในการทำ Regression Testing เพื่อตรวจสอบว่าเกมเวอร์ชันหลัง Refactoring ยังคงทำงานตาม Logic เดิมได้ถูกต้อง

- วิธีทดสอบ: ทดลองเล่นผ่านหน้าจอเกม (Manual Testing)

## 3. ผลการทดสอบ (Baseline Test Results)

### Scenario 1: เริ่มเกมใหม่ (Start a New Game)

**ขั้นตอนการทดสอบ**

1. เปิดเกม
2. เลือกเริ่มเกมใหม่

| -------------- | -------- |
| เงินเริ่มต้น   | 300G     |
| เงินเป้าหมาย   | 5000G    |
| วันที่เริ่มต้น | Day 1/30 |
| พลังงาน        | เต็มหลอด |
| เมล็ดทิวลิป    | 5 เมล็ด  |

**Result: PASS**

### Scenario 2: ปลูกและรดน้ำพืช (Plant and Water Crops)

**ขั้นตอนการทดสอบ**

1. ปลูกเมล็ดทิวลิป 1 เมล็ด
2. รดน้ำแปลงที่ปลูก

**ผลลัพธ์ที่สังเกตได้**

| รายการ        | ผลลัพธ์                               |
| ------------- | ------------------------------------- |
| เมล็ดทิวลิป   | ลดจาก 5 เหลือ 4 เมล็ด                 |
| พลังงาน       | ลดลง โดยแสดงผลเป็นแถบ ไม่มีตัวเลขระบุ |
| แปลงหลังปลูก  | แสดงเมล็ดบนพื้นที่ปลูก                |
| แปลงหลังรดน้ำ | พื้นดินแสดงสถานะเปียก                 |

**Result: PASS**

### Scenario 3: เก็บเกี่ยวและขายผลผลิต (Harvest and Sell Crops)

**ขั้นตอนการทดสอบ**

1. รอจนพืชเติบโตพร้อมเก็บเกี่ยว
2. เก็บเกี่ยวผลผลิต
3. นำผลผลิตไปขาย

**ผลลัพธ์ที่สังเกตได้**

| รายการ                 | ผลลัพธ์                      |
| ---------------------- | ---------------------------- |
| ผลผลิตที่เก็บเกี่ยว    | ทิวลิป 1 ชิ้น                |
| เงินหลังเก็บเกี่ยว     | ไม่เพิ่มขึ้นทันที            |
| สภาพแปลงหลังเก็บเกี่ยว | กลับสู่สภาพเดิมก่อนปลูก      |
| เงินหลังขาย            | เพิ่มขึ้นตามราคาขายของสินค้า |
| จำนวนสินค้าในกระเป๋า   | ลดลงตามจำนวนที่ขาย           |

**ราคาซื้อและขายของพืช**

| พืช                        | ราคาซื้อ | ราคาขาย |
| -------------------------- | -------: | ------: |
| ทิวลิป (Tulip)             |      20G |     60G |
| มันฝรั่ง (Potato)          |      50G |    140G |
| สตรอว์เบอร์รี (Strawberry) |     100G |     60G |

**ข้อสังเกตเพิ่มเติม**
- สตรอว์เบอร์รีสามารถเก็บเกี่ยวผลผลิตจากต้นเดิมได้หลายครั้ง โดยไม่ต้องซื้อเมล็ดพันธุ์มาปลูกใหม่
- ทิวลิปและมันฝรั่งต้องซื้อเมล็ดพันธุ์มาปลูกใหม่หลังจากเก็บเกี่ยวผลผลิตแล้ว

**Result: PASS**

### Scenario 4: จบวันและเริ่มวันถัดไป (End Day and Start the Next Day)

**ขั้นตอนการทดสอบ**

3. ตรวจสอบสถานะเมื่อเริ่มวันถัดไป

| วันที่          | เปลี่ยนเป็นวันถัดไป |
| พลังงาน         | ฟื้นฟูกลับมาเต็ม    |
| สภาพอากาศ       | เปลี่ยนแปลงถูกต้อง  |
| การเติบโตของพืช | ทำงานถูกต้อง        |

**Result: PASS**
