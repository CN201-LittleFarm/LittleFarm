# Test Report

## 1. วัตถุประสงค์

เอกสารนี้จัดทำขึ้นเพื่อบันทึกผลการทดสอบระบบของเกม Little Farm หลังการ Refactoring โดยแยกการทดสอบออกเป็น Automated Unit Testing และ Manual Regression Testing เพื่อเปรียบเทียบพฤติกรรมของเกมก่อนและหลังการปรับปรุงโครงสร้างโค้ด

## 2. สภาพแวดล้อมในการทดสอบ

- ภาษาโปรแกรม: Java
- ส่วนติดต่อผู้ใช้: Java Swing
- คำสั่ง Compile:

  ```bash
  javac -d out src/*.java
  ```

- คำสั่งเปิดเกม:

  ```bash
  java -cp out Main
  ```

## 3. Automated Unit Testing

ทดสอบแต่ละระบบแยกจากเกมหลัก โดยใช้ Test Class และ Mock Data ตามความเหมาะสม

### 3.1 Weather Strategy Test

ไฟล์: `src/WeatherStrategyTest.java`

ทดสอบ:
- การสุ่มสภาพอากาศของ NormalWeatherStrategy
- การสุ่มสภาพอากาศของ RainyWeatherStrategy
- ขอบเขตของค่าที่ใช้ตัดสินผลการสุ่ม
- การเลือก Strategy ผ่าน WeatherStrategyFactory
- การจัดการคำสั่ง `normal`, `rainy` และค่าที่ไม่ถูกต้อง
- การทำงานของ Weather.forecast()

ผลการทดสอบ: **16/16 ผ่าน**

### 3.2 Recipe Test

ไฟล์: `src/RecipeTest.java`

ทดสอบ:
- ข้อมูลสูตร Cake และ Chips
- จำนวนวัตถุดิบที่ต้องใช้
- ระยะเวลาการผลิต
- ราคาขาย
- การตรวจสอบวัตถุดิบในกระเป๋า
- กรณีกระเป๋าเป็น null หรือว่าง
- กรณีวัตถุดิบไม่เพียงพอ
- กรณีมีวัตถุดิบเพียงพอหรือมากกว่าที่กำหนด
- การป้องกันการแก้ไขข้อมูลวัตถุดิบโดยตรง

ผลการทดสอบ: **22/22 ผ่าน**

### 3.3 Processing Machine Test

ไฟล์: `src/ProcessingMachineTest.java`

ทดสอบ:
- สถานะเริ่มต้นของเครื่องแปรรูป
- การเริ่มผลิตเมื่อมีวัตถุดิบเพียงพอ
- การหักวัตถุดิบหลังเริ่มผลิต
- การจัดการกรณีวัตถุดิบไม่เพียงพอ
- การป้องกันการเริ่มผลิตซ้ำขณะที่เครื่องกำลังทำงาน
- การนับจำนวนคืนที่เหลือ
- การเปลี่ยนสถานะเป็น READY เมื่อผลิตเสร็จ
- การป้องกันการเก็บสินค้าก่อนผลิตเสร็จ
- การเก็บสินค้าที่ผลิตเสร็จแล้ว
- การคืนสถานะเครื่องเป็น IDLE หลังเก็บสินค้า
- การจัดการกรณีเรียกคำสั่งไม่ตรงกับสถานะเครื่อง

ผลการทดสอบ: **39/39 ผ่าน**

## 4. Manual Regression Testing

ทดสอบการทำงานของเกมก่อนและหลัง Refactoring โดยใช้ Golden Output เป็นข้อมูลอ้างอิง เพื่อดูว่าการปรับปรุงโครงสร้างโค้ดส่งผลต่อพฤติกรรมเดิมของเกมหรือไม่

### 4.1 รายการทดสอบ

| Scenario | รายละเอียด | ผล |
|---|---|---|
| 1. New Game | ตรวจสอบเงินเริ่มต้น วันในเกม พลังงาน และเมล็ดพันธุ์ | PASS |
| 2. Plant and Water | ตรวจสอบการปลูกเมล็ดพันธุ์ การใช้พลังงาน และสถานะพื้นที่เพาะปลูก | PASS |
| 3. Harvest and Sell | ตรวจสอบการเก็บเกี่ยว การเพิ่มผลผลิต การขาย และเงินที่ได้รับ | PASS |
| 4. End Day | ตรวจสอบการเปลี่ยนวัน การฟื้นฟูพลังงาน สภาพอากาศ และการเติบโตของพืช | PASS |

### 4.2 ผลการทดสอบ

จากการทดลองเล่นเกมหลัง Refactoring พบว่าพฤติกรรมของเกมในสถานการณ์ที่ทดสอบยังคงทำงานได้ตามปกติ และสอดคล้องกับ Golden Output ก่อน Refactoring

ผลการทดสอบ: **4/4 Scenarios Passed**

## 5. ข้อจำกัดในการทดสอบ

- ระบบ Processing Machine ผ่านการทดสอบระดับ Unit Test จำนวน 39 Tests
- ส่วนติดต่อผู้ใช้ (UI) ของ Processing Machine ยังอยู่ระหว่างการพัฒนา จึงยังไม่สามารถทดสอบการใช้งานระบบแปรรูปผ่านเกมหลักได้
- ระบบ Save/Load ยังไม่รวมอยู่ในการทดสอบครั้งนี้ เนื่องจากรอการรวมโค้ดและเตรียมกรณีทดสอบจากผู้รับผิดชอบระบบดังกล่าว

## 6. สรุปผล

การทดสอบ Automated Unit Testing ผ่านทั้งหมด 77 Tests โดยไม่มี Test ใดล้มเหลว และ Manual Regression Testing ผ่านทั้งหมด 4 Scenarios

ผลการทดสอบแสดงให้เห็นว่าระบบที่นำมาทดสอบสามารถทำงานได้ตามกรณีที่กำหนด และการ Refactoring ไม่ทำให้พฤติกรรมเดิมของเกมในสถานการณ์ที่ทดสอบเปลี่ยนแปลงไป

อย่างไรก็ตาม ยังต้องทดสอบการทำงานร่วมกับ UI ของ Processing Machine และระบบ Save/Load อีกครั้งหลังจากการพัฒนาและรวมโค้ดเสร็จสมบูรณ์
