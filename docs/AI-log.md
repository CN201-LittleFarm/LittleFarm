# บันทึกการใช้งาน AI (AI Usage Log)

## Project: Little Farm

เอกสารนี้จัดทำขึ้นเพื่อบันทึกการใช้ AI เป็นเครื่องมือช่วยสนับสนุนการพัฒนา การทดสอบ และการจัดทำเอกสารของโปรเจกต์ Little Farm โดยสมาชิกในทีมยังคงเป็นผู้ตรวจสอบ ปรับปรุง และตัดสินใจเลือกใช้ผลลัพธ์ก่อนนำไปใช้งานจริง

## เครื่องมือ AI ที่ใช้ (AI Tools Used)

- ChatGPT
- Gemini
- Claude (Anthropic) รุ่น Claude Sonnet 5.5

## รายละเอียดการใช้งาน AI (AI Assistance)

| ระบบ / งานที่ทำ | AI ที่ใช้ | สิ่งที่ AI ช่วยเหลือ | สิ่งที่สมาชิกตรวจสอบและแก้ไขเอง |
|---|---|---|---|
| Processing Recipe System | Gemini | ช่วยเขียนคำสั่ง Terminal สำหรับสร้าง แก้ไข และลบไฟล์ ช่วยอ่าน Source Code และตรวจสอบเครื่องมือที่อาจารย์เตรียมไว้ รวมถึงช่วยอธิบาย Java Syntax และ OOP | ตรวจสอบและปรับโค้ดด้วยตนเอง เช่น จำกัดวัตถุดิบให้ตรงตามที่กำหนด และกำหนดการสืบทอดคลาส `BaseRecipe` จาก `ProcessingRecipe` |
| Weather Strategy System | ChatGPT | ช่วยออกแบบระบบโดยใช้ Strategy Pattern และ Factory Pattern รวมถึงแนะนำการเชื่อมต่อโค้ดกับระบบเดิม | ตรวจสอบและทดลองการทำงานของระบบ รวมถึงปรับแก้โค้ดให้เข้ากับโครงสร้างเกม |
| Processing Machine System | ChatGPT | ช่วยวางแผนการทำงาน อธิบายโครงสร้างคลาส การจัดการสถานะของเครื่องแปรรูป และตรวจสอบข้อผิดพลาด | ตรวจสอบเงื่อนไขการทำงาน ทดลองรัน Unit Tests และตรวจสอบผลลัพธ์ด้วยตนเอง |
| Save/Load System | Claude (Anthropic) | ช่วยออกแบบโครงสร้างระบบ Save/Load โดยแยกหน้าที่ของ `SaveGame` สำหรับอ่านและเขียนไฟล์ ออกแบบ Exception โดยให้ `CorruptSaveException` และ `UnreadableSaveException` สืบทอดจาก `FarmException` รวมถึงออกแบบ Interface `SavableMachine` เพื่อให้ระบบ Save/Load รองรับเครื่องแปรรูปโดยไม่ต้องรอการพัฒนาโค้ดจากสมาชิกคนอื่น | ตรวจสอบและปรับโครงสร้างให้เหมาะสมกับความรู้และเนื้อหา Java OOP ที่เรียนมา รวมถึงตรวจสอบการเชื่อมต่อกับระบบเดิม |
| Save/Load Implementation | Claude (Anthropic) | ช่วยพัฒนา `CorruptSaveException`, `UnreadableSaveException`, `SavableMachine` และปรับปรุง `SaveGame` ให้ตรวจสอบความถูกต้องของไฟล์เซฟ แจ้งหมายเลขบรรทัดที่เกิดข้อผิดพลาด รองรับการอ่านและเขียนไฟล์ UTF-8 และใช้ไฟล์ชั่วคราวก่อนบันทึกจริง นอกจากนี้ยังช่วยแก้เมธอด `load` ใน `FarmScreen` ให้แสดงกล่องแจ้งเตือนเมื่อเกิดข้อผิดพลาด แทนการเริ่มฟาร์มใหม่โดยไม่แจ้งให้ผู้เล่นทราบ | ตรวจสอบและแก้ไขกรณีที่ AI ไม่ครอบคลุม เช่น การแจ้งหมายเลขบรรทัดและข้อผิดพลาดที่อาจเกิดขึ้นเพิ่มเติม รวมถึงปรับโค้ดให้เข้าใจและดูแลต่อได้ง่ายขึ้น |
| Save/Load Testing | Claude (Anthropic) | ช่วยเขียน `SaveGameTest` จัดเตรียมไฟล์เซฟตัวอย่าง และไฟล์เซฟที่ตั้งใจทำให้ข้อมูลผิดพลาด พร้อมกำหนดผลลัพธ์ที่คาดหวังและหมายเลขบรรทัดที่ควรแจ้งเตือน | รัน Unit Tests ด้วยตนเองจนผ่านทั้งหมด 35 กรณี และทดลองเปิดเกมจริงโดยลบบรรทัด `gold` ออกจากไฟล์เซฟ เพื่อตรวจสอบว่าเกมแจ้งเตือนข้อผิดพลาดได้ตามที่ออกแบบไว้ |
| Automated Unit Testing | ChatGPT | ช่วยออกแบบกรณีทดสอบสำหรับ Recipe, Processing Machine และ Weather Strategy | รันการทดสอบด้วยตนเองและตรวจสอบผลลัพธ์ในโปรเจกต์ |
| Manual Regression Testing | ChatGPT | ช่วยจัดทำ Golden Output และวางสถานการณ์ทดสอบเพื่อเปรียบเทียบพฤติกรรมเกมก่อนและหลัง Refactoring | ทดลองเล่นเกมจริงและบันทึกผลลัพธ์ที่สังเกตได้ |
| Test Documentation | ChatGPT | ช่วยจัดทำ Test Report และ Class Diagram เพื่ออธิบายผลการทดสอบและโครงสร้างคลาส | ตรวจสอบเนื้อหาและความสัมพันธ์ของคลาสให้ตรงกับ Source Code จริง |

## ข้อจำกัดในการใช้งาน AI (Limitations)

- คำแนะนำหรือโค้ดที่ AI สร้างขึ้นอาจมีข้อผิดพลาดหรือไม่ตรงกับข้อกำหนดของโปรเจกต์
- ในการพัฒนาระบบ Save/Load รอบแรก Claude เสนอแนวทางและโค้ดที่มีความซับซ้อนเกินกว่าความรู้พื้นฐานของสมาชิก ทำให้แก้ไขและปรับปรุงได้ยาก ทีมจึงปรับโค้ดให้เรียบง่ายขึ้นและสอดคล้องกับหลักการ Java OOP ตามเนื้อหาที่เรียนในชั้นเรียน
- สมาชิกมีการปรับแก้หรือตัดบางส่วนที่ AI แนะนำออก เพื่อให้ตรงกับขอบเขตงานและโครงสร้างของโปรเจกต์
- สมาชิกตรวจสอบและเพิ่มเติมกรณีข้อผิดพลาดที่ AI อาจไม่ได้ครอบคลุม โดยเฉพาะการแจ้งหมายเลขบรรทัดของไฟล์เซฟที่เสียหาย
- ผลการทดสอบทั้งหมดได้รับการตรวจสอบด้วยการรันโปรแกรมจริง
- เอกสารและแผนภาพได้รับการตรวจสอบให้สอดคล้องกับ Source Code ก่อนนำไปใช้งาน

## สรุป (Conclusion)

ทีมใช้ AI เป็นเครื่องมือช่วยในการออกแบบระบบ พัฒนาโค้ด ตรวจสอบข้อผิดพลาด ออกแบบการทดสอบ และจัดทำเอกสาร โดยสมาชิกเป็นผู้ตัดสินใจเลือกแนวทาง ปรับปรุงโค้ด ทดสอบ และตรวจสอบความถูกต้องก่อนนำไปใช้จริง

ในการพัฒนาระบบ Save/Load สมาชิกยังได้นำความรู้ Java OOP เบื้องต้นจากเนื้อหาที่เรียนมา เช่น Inheritance, Encapsulation และการใช้ `throw` เพื่อจัดการ Exception มาประยุกต์ใช้ในการตรวจสอบและปรับปรุงโค้ดที่ได้รับความช่วยเหลือจาก AI
